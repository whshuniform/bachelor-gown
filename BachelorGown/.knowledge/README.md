# 專案知識庫

本目錄存放專案的累積知識，供 Claude 和開發者查閱。

## 檔案索引

| 檔案 | 內容 | 查閱時機 |
|------|------|---------|
| `architecture.md` | 架構決策、技術選型理由 | 理解「為什麼這樣設計」時 |
| `api-catalog.md` | 外部 API / 服務整合清單 | 查詢第三方整合細節時 |
| `module-map.md` | 頁面、元件、layout 對應關係 | 理解模組邊界、決定程式碼放哪裡時 |
| `deployment.md` | 部署流程、環境設定 | 部署、環境問題排查時 |
| `pitfalls.md` | 踩過的坑與解法 | 遇到怪問題、或開發類似功能前 |
| `changelog.md` | 知識庫變更紀錄 | 確認知識庫是否過時時 |

## 維護規則

- 完成功能或解完 bug 後執行 `/kb.update` 更新知識庫
- 每個條目標注更新日期，方便判斷時效性
