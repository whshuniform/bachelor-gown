# 外部 API / 服務整合清單

> 最後更新：2026-06-01

本站為純靜態站，無自建後端 API。以下記錄外部服務整合。

## 第三方服務

| 服務 | 用途 | 說明 |
|------|------|------|
| YouTube embed | 各屆回顧影片 | `<iframe>` 嵌入，URL 格式：`https://www.youtube.com/embed/<id>` |
| Google Analytics（gtag） | 流量分析 | `plugins/gtag.js`，client-side only |
| Facebook Open Graph | 社群分享預覽 | `fb:app_id: 246786583555444`，各頁設定 og:image / og:description |
